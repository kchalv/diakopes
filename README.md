# Οικονομικές οικογενειακές διακοπές

Στους servers του GitHub (GitHub Actions) σαρώνονται τιμές για 5 άτομα: 3 ενήλικες (42, 43 και 13 ετών)
και 2 παιδιά (9 και 11). Μια τιμή κρίνεται ως πραγματική προσφορά με βάση το ιστορικό. Για τις εξαιρετικές
στέλνεται email και η σελίδα ανανεώνεται στο **https://kchalv.github.io/diakopes/** (αποθετήριο: https://github.com/kchalv/diakopes).
Ο υπολογιστής δεν χρειάζεται να είναι ανοιχτός.

## Προορισμοί
Με αναχώρηση και επιστροφή **μόνο από Αθήνα**: Ισπανία, Ιταλία, Ελβετία, Δανία, Πορτογαλία, Αγγλία,
Σκωτία, Γαλλία και ΗΠΑ (`config.json` → `destinations`· Ουαλία και Βόρεια Ιρλανδία εξαιρούνται).

## Περίοδος και αεροπορικές
- **Περίοδος**: όλο το ταξίδι από 20 Ιουνίου έως και 5 Σεπτεμβρίου (`config.json` → `travel`), σε 11
  διαδοχικές εβδομάδες των 7 νυχτών. Για κάθε προορισμό και εβδομάδα γίνεται μία αναζήτηση πτήσεων.
- **Αεροπορικές**: όλες εκτός από Ryanair, easyJet, Sky Express, Wizz Air και Vueling (`config.json` → `excluded_airlines`).
  Κόβονται και τα δρομολόγια όπου μία από αυτές κάνει έστω ένα σκέλος. Για να κοπεί κι άλλη εταιρεία,
  αρκεί να προστεθεί το όνομά της στη λίστα.
- **Μόνο απευθείας πτήσεις** (`config.json` → `nonstop_only`). Προορισμοί ή εβδομάδες χωρίς απευθείας πτήση
  από επιτρεπόμενη εταιρεία δεν εμφανίζονται.
- **Τιμή για 5**: το Google Flights συχνά δεν δείχνει όλες τις εταιρείες (π.χ. Aegean, ITA, TAP) όταν ζητούνται
  5 θέσεις μαζί. Γι' αυτό κάθε αναζήτηση γίνεται σε δύο κρατήσεις στην ίδια πτήση (1 ενήλικας + 2 παιδιά, και
  2 ενήλικες) και οι τιμές αθροίζονται.
- **Πακέτα με ξενοδοχείο**: ξενοδοχείο ψάχνεται μόνο για τις εβδομάδες όπου τα αεροπορικά προς το ίδιο μέρος έχουν
  έκπτωση (έως 3 εβδομάδες ανά μέρος), στο ίδιο μέρος και τις ίδιες ημερομηνίες. Όσο ένας προορισμός δεν
  έχει ακόμη έκπτωση (π.χ. τις πρώτες μέρες, χωρίς ιστορικό), μπαίνει η φθηνότερη εβδομάδα πτήσεών του.
- **Διαμονή μόνο σε οργανωμένα ξενοδοχεία** (όχι Airbnb, διαμερίσματα ή hostels): 3 αστέρια και πάνω
  (`config.json` → `scrape.min_hotel_stars`· με 4 η επιλογή γίνεται πιο αυστηρή) με βαθμολογία 4+ και
  τουλάχιστον 300 κριτικές. Κόβονται επίσης ονόματα με λέξεις όπως hostel/ostello/apartments και τιμές πολύ
  κάτω από τα υπόλοιπα (κρεβάτι σε κοιτώνα). Τα ξενοδοχεία σχεδόν ποτέ δεν δίνουν τιμή για
  5 άτομα σε ένα δωμάτιο, γι' αυτό η οικογένεια ψάχνεται σε δύο δωμάτια του ίδιου ξενοδοχείου (2 ενήλικες, και
  1 ενήλικας + 2 παιδιά) και οι τιμές αθροίζονται. Κάθε ξενοδοχείο έχει σύνδεσμο προς το Booking.com για τις
  ίδιες ημερομηνίες, 5 άτομα και 2 δωμάτια.

Κάθε **ολοκληρωμένη πρόταση** (πακέτο) έχει: πτήση με επιστροφή από Αθήνα για 5 άτομα, με όλες τις
επιτρεπόμενες εταιρείες που βρέθηκαν για τις ημερομηνίες, και το φθηνότερο καλό ξενοδοχείο για την ίδια εβδομάδα.
**Κάθε σάρωση ελέγχει όλους τους προορισμούς και όλες τις εβδομάδες** (20 προορισμοί × 11 εβδομάδες = 220 αναζητήσεις πτήσεων,
όλες οι επιτρεπόμενες αεροπορικές) και ξενοδοχεία για όλες τις εβδομάδες με έκπτωση. Στο GitHub οι αναζητήσεις πτήσεων
μοιράζονται σε 5 παράλληλα τμήματα (εργασία `flights`), το καθένα σε δικό του server, και η εργασία `scan` τα ενώνει.

## Πηγές
| Πηγή | Τι δίνει | Τρόπος |
|---|---|---|
| Google Flights | Όλες οι αεροπορικές εκτός των εξαιρούμενων (Aegean, Lufthansa, Swiss, BA, Iberia, ITA, SAS, Delta…) με τιμή για 5 | browser (Playwright) |
| Google Hotels | Ξενοδοχεία 3★+ με βαθμολογία 4+ (συγκεντρώνει τιμές Booking.com, Expedia κ.ά.), τιμή για 5 σε δύο δωμάτια | browser |
| Fly4free | Μόνο προσφορές με αναχώρηση από Αθήνα προς τους παραπάνω προορισμούς | RSS |

Αφαιρέθηκαν HolidayPirates, TravelPirates, Travelzoo και Urlaubspiraten, γιατί πουλάνε πακέτα με
πτήσεις από Βρετανία/Γερμανία για πελάτες εκείνων των χωρών. Το Airbnb αφαιρέθηκε (θέλουμε μόνο
οργανωμένα ξενοδοχεία). Το Booking.com και το Skyscanner μπλοκάρουν τους αυτοματοποιημένους browsers
(το Booking.com τους δίνει σελίδα χωρίς καταλύματα), γι' αυτό οι τιμές των ξενοδοχείων διαβάζονται από το
Google Hotels και το Booking.com εμφανίζεται ως έτοιμος σύνδεσμος κράτησης σε κάθε ξενοδοχείο.
Αν το Google Hotels δώσει λάθος προορισμό ή νόμισμα (συνέβαινε παλιότερα από τους servers του GitHub),
η αναζήτηση απορρίπτεται και καταγράφεται ως σφάλμα αντί να εμφανιστούν λάθος τιμές.

## Πώς λειτουργεί online
- `.github/workflows/scan.yml`: η σάρωση, στόχος περίπου **κάθε 5 ώρες**. Το δικό του cron (κάθε ώρα)
  μένει ως εφεδρεία, γιατί το GitHub συχνά το καθυστερεί ή το παραλείπει σε δημόσια αποθετήρια.
  Μια εργασία «gate» δεν αφήνει δεύτερη σάρωση μέσα σε 3,5 ώρες, εκτός αν ξεκινήσει χειροκίνητα.
  Χειροκίνητη εκτέλεση: καρτέλα **Actions → Σάρωση προσφορών → Run workflow** (τρέχει πάντα).
- **Εξωτερικό ξυπνητήρι**: cloud ρουτίνα Claude (https://claude.ai/code/routines) κάθε 5 ώρες κάνει ένα κενό
  commit στον κλάδο `claude/wake`. Το `.github/workflows/wake.yml` το πιάνει και ξεκινά τη σάρωση στο `main`.
  Χρειάζεται το GitHub να είναι συνδεδεμένο στον λογαριασμό Claude (https://claude.ai/connect-github).
- Το ιστορικό τιμών (`prices.db`) φυλάγεται στον κλάδο `data` και κρατιέται μόνο η τελευταία έκδοση.
- Τα στοιχεία email (διευθύνσεις, server, κωδικός) είναι στο κρυφό **Secret `DIAKOPES_EMAIL`**
  (Settings → Secrets and variables → Actions) και δεν εμφανίζονται πουθενά στον κώδικα.
  Μορφή: `{"to":"…","from":"…","smtp_host":"…","smtp_user":"…","smtp_password":"…"}`.
  Το `to` δέχεται πολλές διευθύνσεις χωρισμένες με κόμμα (το email πάει σε όλες).
  Αν αλλάξετε τον κωδικό του email ή τους παραλήπτες, ενημερώστε αυτό το Secret
  (ή τοπικά: `python -c "import json,notify;print(json.dumps(notify.settings()))" | gh secret set DIAKOPES_EMAIL`).
- Το αποθετήριο είναι δημόσιο, ώστε τα Actions και το Pages να είναι δωρεάν.

## Τοπικά (προαιρετικά)
```powershell
pip install -r requirements.txt; python -m playwright install chromium
python collector.py --no-scrape   # γρήγορα, χωρίς browser: RSS + όσα είναι ήδη αποθηκευμένα
python notify.py --test-email     # δοκιμή email (στοιχεία στο secrets.json, που δεν ανεβαίνει)
start site\index.html
```

## Αρχεία
- `config.json`: οικογένεια, αεροδρόμια, προορισμοί, κανόνες «προσφοράς».
- `collector.py`: κύρια σάρωση. `scrapers.py`: browser scraping. `notify.py`: email.
- `site/index.html`: η σελίδα. Το `data.js` παράγεται σε κάθε σάρωση.
